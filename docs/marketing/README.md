# AyniPOS - Base de Marketing

Esta guía resume como vender AyniPOS con mensajes claros, creíbles y alineados al estado actual del producto.

## 1. Qué es AyniPOS

AyniPOS es un sistema de punto de venta de escritorio para pequeños y medianos comercios que necesitan vender rápido, controlar inventario y tener reportes claros sin depender de una conexión permanente a internet.

## 2. Propuesta de valor

**"AyniPOS te ayuda a vender más rápido, controlar tu stock con orden y entender tu negocio sin complicarte."**

Puntos fuertes actuales:

- Punto de venta ágil con atajos de teclado y lector de código de barras
- Control de inventario con edición, importación/exportación y trazabilidad
- Control de lotes y vencimiento
- Reportes de ventas, margen e inventario
- Multiusuario con PIN, roles y registro de actividad
- Cierre de caja y respaldos
- App de escritorio, útil para negocios que no quieren depender siempre del navegador

## 3. Cliente ideal

Prioridad alta:

- Tiendas de barrio
- Minimarkets
- Farmacias pequeñas
- Licorerías
- Kioscos con alto movimiento

Prioridad media:

- Ferreterías pequeñas
- Tiendas de cosméticos
- Distribuidoras pequeñas con mostrador

## 4. Problemas que resuelve

No vendas el software como "un POS". Véndelo como solución a dolores concretos:

- "No sé cuánto stock me queda realmente"
- "Mis cajeros se equivocan o venden lento"
- "No sé qué producto me deja más ganancia"
- "No tengo claro cuánto se vendió hoy"
- "No sé quién hizo cambios en caja o inventario"
- "Quiero orden sin usar cuadernos ni Excel para todo"

## 5. Posicionamiento recomendado

Posición principal:

**AyniPOS es un sistema simple, rápido y ordenado para negocios que ya crecieron más allá del cuaderno y Excel.**

Posición alternativa para farmacias y rubros sensibles:

**AyniPOS te ayuda a vender con rapidez y a controlar productos, lotes y vencimientos con más tranquilidad.**

## 6. Mensajes por segmento

### Tiendas y minimarkets

- Cobra rápido con teclado y código de barras
- Mira tus ventas del día en segundos
- Controla stock sin hacer cuentas manuales
- Identifica productos más vendidos y más rentables

### Farmacias pequeñas

- Lleva control de lotes y fechas de vencimiento
- Reduce errores al vender
- Consulta movimientos y responsables

### Negocios con varios empleados

- Cada usuario entra con su PIN
- Define roles y permisos
- Revisa qué hizo cada persona
- Asocia cada turno de caja a su cajero

## 7. Diferenciadores que sí puedes prometer hoy

Usa mensajes que ya están respaldados por el producto:

- Venta rápida con lector y atajos
- Reportes útiles para tomar decisiones
- Trazabilidad de inventario y usuarios
- Operación de escritorio
- Soporte para recibos y cierre de caja

Estas funciones aparecen en el roadmap, pero todavía no conviene venderlas como beneficio presente.

## 11. Estructura de demo de 15 minutos

1. Crear confianza
   Pregunta primero cómo venden hoy y qué les hace perder tiempo.
2. Mostrar velocidad
   Enseña cobro rápido, búsqueda de productos, teclado y código de barras.
3. Mostrar control
   Enseña inventario, lotes, historial y usuarios.
4. Mostrar dinero
   Enseña reportes de ventas, margen y cierre de caja.
5. Cerrar
   Propón prueba, instalación o visita.
